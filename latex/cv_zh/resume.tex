\begin{rSection}{近期主要项目}
\begin{rSubsection}{\hspace*{-1.5em}实时流式可交互数字人}{2025/11-至今}{产品落地：数字人；科研产出：\href{https://liveanimate.github.io/}{LiveAnimate}、\href{https://uniswap-av.github.io/}{UniSwap}、\href{https://rethinking-cfg-opd.github.io/}{PDM}}{千问App}
\item {\bf 技术挑战：}如何让Diffusion类数字人系统在保证画质、身份一致性与音画同步的同时，实现实时、长时流式生成与低成本交互控制？
\item {\bf 解决方案：}主导构建实时流式数字人生成技术体系。针对扩散模型推理延迟高、长时生成易产生误差累积的问题，通过块因果自回归架构与有界 KV Cache 实现增量式长视频生成，并结合少步扩散蒸馏、序列并行及算子优化，将视频生成速度提升至实时水平，同时保持长时身份与画质稳定性。针对交互控制成本高的问题，提出分支感知的在策略蒸馏方法，将逐帧稠密控制能力迁移至稀疏关键帧，支持姿态、深度与涂鸦等交互条件；进一步构建统一音视频身份替换模型，实现人物外观与音色的同步迁移，并保持原视频的动作、内容及音画时序。
\item {\bf 效果：}实现 14B/22B 级视频生成模型的实时流式推理，最高达到 19.63 FPS，并在长时生成中保持身份、画质与音画同步稳定；支持姿态、深度与涂鸦等稀疏关键帧交互控制，视频蒸馏训练成本降低约 6 倍。
\end{rSubsection}

\begin{rSubsection}{\hspace*{-1.5em}面向高质量图像/视频生成的创作Agent系统}{2025/11-至今}{产品落地：AI生图、AI剧场；科研产出：\href{https://ava-encoder.github.io/}{AVA-Encoder}、\href{https://haozheh3.github.io/SearchGen/}{SearchGen}}{千问App}
\item {\bf 核心问题：}如何让创作Agent理解视频中的细粒度时空结构？如何让Agent在面对时效性、长尾及知识密集型需求时生成内容准确的图像？
\item {\bf 解决方案：}
\begin{itemize}
\setlength{\itemsep}{0em}
\setlength{\topsep}{0em}
\setlength{\parsep}{0em}
\item {\bf 视频Agent：}由于LM自身局限性，现有视频创作Agent主要依赖文本描述进行规划，缺少能够从高质量视频数据中学习的结构化中间表征。主导设计面向Agent的 Encoder-Decoder 架构，将视频编码为Agent原生（Agent-Native）的结构化表征，使其能够理解和复用视频中的内容、运动与时序信息，提升规划模型（Planner）训练及视频复刻、编辑等下游任务的效果。
\item {\bf 图像Agent：}针对生成模型难以覆盖时效性与长尾视觉知识、无差别检索又容易引入噪声的问题，设计搜索增强的图像生成Agent，使其能够识别生成模型的知识边界，自主判断是否需要搜索，并对外部图文信息进行检索、筛选与整合；进一步通过生成模型与搜索Agent的协同训练，持续拓展模型的知识边界，提升知识密集型图像生成的准确性。
\end{itemize}
\item {\bf 效果：}视频侧，AVA-Encoder 较最强外部基线方法提升 20.7 个百分点；在减少 74.3\% 系统提示词 Token 的同时，性能超过人工调优策略。图像侧，在固定 4B 生成模型上，SearchGen 将知识密集型图像生成总体得分由 25.0 提升至 31.8，并以 8B 搜索 Agent 达到与前沿推理模型相当的效果（31.8 vs. 31.2）。
\end{rSubsection}

\begin{rSubsection}{\hspace*{-1.5em}创作对话中的主动响应式推荐系统}{2025/11-至今}{产品落地：AI生图；科研产出：\href{https://what-to-edit-next.github.io/}{What to Edit Next}}{千问App}
\item {\bf 核心问题：}如何基于海量用户创作与对话数据，主动理解并延续用户创作意图，提升普通用户的创作效率、活跃度与留存？
\item {\bf 解决方案：}主导设计并落地创作对话主动推荐系统，融合历史对话上下文、当前创作意图与生成结果，预测用户后续编辑需求，并生成可直接执行的编辑建议（PAA, People Also Ask）。基于海量线上数据归纳 60 余类创作意图，完成 Prompt Engineering、SFT 与 RLHF 三阶段架构迭代，从意图准确性、可执行性与点击吸引力等维度持续优化推荐效果。
\item {\bf 效果：}日均百万量级曝光，用户平均点击率（CTR）提升 32.7\%，图片取走率提升 16.32\%，人均对话轮次提升 39.9\%
\end{rSubsection}
